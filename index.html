Featured project

Lantern

A local agent that keeps watch over a repository. On a heartbeat it scans the logs, reads the bug inbox and runs the tests, then files what it finds as tickets in a SQLite ledger it owns. Tickets it can handle go to Claude Code sessions, which open draft pull requests for review. Only decisions that need a human reach me, and a local web page shows what it noticed, did and spent.

TypeScript · Node.js · SQLite · Claude Code
